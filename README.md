# Clipr — URL Shortener 🔗

A clean, minimal URL shortener with a beautiful Apple-inspired UI.

## 🌐 Live Demo
**[clipr.live → https://tharun-0106.github.io/Clipr-UrlShorterningTool/](https://tharun-0106.github.io/Clipr-UrlShorterningTool/)**

## ✨ Features
- ✂️ Shorten any long URL instantly
- 📊 Track click counts in real time
- 🗂️ View and manage all your links
- 🗑️ Delete links anytime
- 📱 Fully responsive — works on mobile

## 🛠️ Tech Stack
- HTML, CSS, JavaScript (Vanilla)
- Hosted on **GitHub Pages**
- Connects to a **Spring Boot REST API**

## 📦 Backend
> Built with Spring Boot + PostgreSQL
> [View Backend Repository](https://github.com/tharun-0106/Clipr-backend)

## 🚀 How it works
1. Paste any long URL
2. Hit Shorten
3. Share your short link
4. Track how many times it gets clicked
